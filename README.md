# 📱 Desenvolvimento Mobile — React Native + Expo

Exercícios e desafios desenvolvidos durante a disciplina de Desenvolvimento
Mobile, utilizando **React Native** com **Expo**.

## 🛠️ Stack

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- TypeScript
- Expo Go (para testes em dispositivo físico)

## 📂 Estrutura do repositório

Cada exercício é um projeto Expo independente, numerado sequencialmente.

```
mobile-dev-bsi/
├── exercises/
│   ├── 01-social-post-card/
│   ├── 02-.../
│   └── 03-.../
└── final-project/
```

## 📋 Exercícios

| #   | Nome                                                | Descrição                                                                   |
| --- | --------------------------------------------------- | --------------------------------------------------------------------------- |
| 01  | [Social Post Card](./exercises/01-social-post-card) | Card estilizado de post de rede social com avatar, nome do autor e mensagem |

## 🚀 Como rodar um exercício

```bash
cd exercises/01-social-post-card
npm install
npx expo start
```

Escaneie o QR Code com o app **Expo Go** (Android/iOS), ou rode em um
emulador com `npx expo start --android` / `--ios`.

## 📋 Requisitos

- Node.js (LTS)
- npm ou yarn
- App **Expo Go** instalado no celular (ou emulador Android/iOS configurado)
